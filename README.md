# R You Reproducible? Making the Most of Your Microbiome (Meta)data

Hands-on workshop at the **4th African Microbiome Symposium**, Biomedical Research Institute, Stellenbosch University, Cape Town.

In one morning you will build a small reproducible project, clean and harmonise messy sample metadata from three (synthetic) study sites using community standards, and finish with a report that reruns from raw data to results, plus a draft Methods section that reports exactly what was done.

## Before the workshop

1.  **Download this repository.** Click the green **Code** button at the top of this page, then **Download ZIP**, and unzip it somewhere easy to find (e.g. your Documents folder). You do not need Git or a GitHub account.
2.  **Install the software** (R, RStudio and the R packages). Step-by-step instructions are in [SETUP.md](SETUP.md).
3.  **Run the setup check.** Open `r-you-reproducible.Rproj` in RStudio, open `check_setup.R` and click **Source**. It should end with `ALL CHECKS PASSED`.
4.  **Cannot install software on your laptop?** Use Posit Cloud in your web browser instead (free; instructions in [SETUP.md](SETUP.md#option-b-posit-cloud-no-installation)).

Please bring your laptop and charger. If the setup check fails, email Kristien: [**knvz\@sun.ac.za**](mailto:knvz@sun.ac.za) with a screenshot of the output before the workshop, so we can help you in advance.
